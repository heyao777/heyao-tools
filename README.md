# 河妖 HeYao Tools

一个为个人学习、写作、求职和 AI 使用场景打造的中文效率工具箱。

## 核心功能

- Prompt 语义诊断
- Prompt 优化改写
- 角色提示词生成
- 文本清洗
- 求职表达优化

## 技术栈

- Sites vinext starter
- Next.js
- React
- TypeScript
- Tailwind CSS

## 启动方式

```bash
npm install
npm run dev
```

## 构建方式

```bash
npm run build
```

## 项目目标

把日常重复出现的文本处理和 AI 提问流程整理成可复用工具，减少重复操作，提高个人效率。

V1 版本暂不接入真实 AI API，使用前端规则、模板和模拟逻辑完成交互闭环。
